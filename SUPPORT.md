# Support

## Getting Help

Before opening an issue:

1. Check the [README](./README.md).
2. Search existing issues.
3. Review [DEPLOYMENT.md](./DEPLOYMENT.md) for deployment problems.
4. Review [PRIVACY.md](./PRIVACY.md) for data and browser-storage questions.

## Bug Reports

Use the Bug Report issue template and include:

- Browser and version
- Device and screen size
- Page URL or file
- Reproduction steps
- Expected and actual result
- Console errors when available

## Feature Requests

Use the Feature Request issue template. Explain the user problem before proposing the implementation.

## Security or Privacy

Do not open a public issue. Follow [SECURITY.md](./SECURITY.md).
