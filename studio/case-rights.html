信任关系必须能被公开验证

网站编号不是一个装饰文字，而是可以被查询、复制和嵌入其他站点的公开凭据。

01 / REGISTER

登记与审核

提交网站信息、域名和版权所有者，经过审核后生成公开记录。

02 / VERIFY

编号与徽章

公开查询页面、认证徽章和官网编号让访客能够核对域名与权利信息。

03 / OPERATE

状态与接口

状态页、事件记录、开发者 API 和运维中心支持后续长期维护。

完成结果

版权中心已经独立运行，并与制作方官网、工具平台和个人站点建立清晰跳转关系。
