# Maintainers

## Project Owner

- [@HQUGH16FHJ](https://github.com/HQUGH16FHJ)
- Role: owner, maintainer, release manager, security contact
- Scope: frontend, documentation, branding, deployment, repository governance

## Maintainer Responsibilities

- Review issues and pull requests
- Protect user data and backend contracts
- Keep documentation and releases current
- Verify desktop, tablet, mobile, WeChat, and Android Edge
- Maintain license and brand integrity
- Handle security reports privately

## Code Ownership

The repository uses `.github/CODEOWNERS` to route all changes to the project owner.

## Becoming a Maintainer

Maintainer access is granted only by the project owner. Consistent, high-quality contributions may be considered, but contributing does not automatically grant ownership or redistribution rights.
