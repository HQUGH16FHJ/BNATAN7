# Governance

## Project Ownership

绊谈 · 万能枢纽 is maintained by 绊谈 Bantan. Final decisions on branding, licensing, architecture, public releases, and backend contracts belong to the project owner.

## Decision Levels

| Change | Decision |
|---|---|
| Documentation, typos, accessibility fixes | Maintainer review |
| Frontend components and visual changes | Maintainer review and cross-device verification |
| Shared navigation, cache, authentication, VIP, or API behavior | Project owner approval |
| License and branding changes | Project owner only |

## Review Principles

- Preserve the existing product and visual language.
- Keep backend and frontend boundaries explicit.
- Prefer measurable improvements over broad rewrites.
- Do not introduce secrets into client files.
- Require evidence for cross-device or caching changes.

## Release Authority

Only the project owner may publish official releases, signed tags, or production deployment packages.

## Conflict Resolution

Technical disagreement should be resolved with reproducible evidence. If no consensus is reached, the project owner makes the final decision.
