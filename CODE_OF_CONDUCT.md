# Code of Conduct

## Our Standard

Participation in this project should remain respectful, constructive, and focused on improving the product.

Examples of positive behavior:

- Giving clear technical feedback
- Respecting different devices, languages, and accessibility needs
- Accepting correction and revising conclusions when evidence changes
- Keeping discussions relevant to the repository

Examples of unacceptable behavior:

- Harassment, threats, discrimination, or personal attacks
- Publishing private information without permission
- Submitting secrets, private user data, or malicious code
- Spam, deception, or deliberate disruption
- Encouraging illegal, harmful, or abusive use of the project

## Scope

This code applies to issues, pull requests, discussions, reviews, and other spaces managed by the project.
