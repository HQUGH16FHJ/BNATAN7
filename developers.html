本地运行

静态网站建议通过 HTTP 服务访问，避免 Service Worker 和相对路径失效。

python -m http.server 8000

随后打开 http://localhost:8000/landing.html。

部署检查

  • 域名和相对路径正确。
  • Service Worker 缓存版本已更新。
  • 许可证、llms.txt、robots.txt 和 sitemap.xml 可访问。
  • 手机、平板、桌面和微信内置浏览器完成复核。
  • 后台、VIP、注册登录和用户接口不被覆盖。
