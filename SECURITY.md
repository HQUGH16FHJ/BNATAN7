# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| v4.0.x | Yes |
| v3.x and older | No |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in a public issue.

Send a private report to:

- Email: g125668039@163.com
- GitHub: [@HQUGH16FHJ](https://github.com/HQUGH16FHJ)

Include:

- A clear description of the issue
- Steps to reproduce
- Affected page, file, or endpoint
- Browser and device information
- Potential impact
- Screenshots or proof of concept when safe to share

## Sensitive Information

Never submit passwords, access tokens, API keys, private user data, payment data, or production environment secrets in an issue, pull request, screenshot, or commit.

If a secret was exposed:

1. Revoke or rotate it immediately.
2. Remove it from the current revision.
3. Review deployment logs and connected services.
4. Report the incident privately.

## Scope

Security reports are especially welcome for:

- Authentication or session handling
- User data exposure
- Cross-site scripting
- Unsafe HTML or script injection
- Broken access control
- Sensitive information in frontend files
- Service Worker cache poisoning
- Malicious third-party links

The response target is an initial acknowledgement within 7 days. Resolution time depends on severity and reproducibility.
