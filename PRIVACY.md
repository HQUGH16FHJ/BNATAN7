# Privacy

This document explains the privacy behavior of the repository and public website.

## Browser Storage

The frontend may use `localStorage` or `sessionStorage` for:

- Login session state
- User preferences
- Recently used tools
- Pending search terms
- Motion and theme preferences
- Local profile customization

Clearing browser storage may reset these local settings.

## AI Features

When using the hosted AI mode, the message needed to answer the request may be sent to the configured AI service or project proxy. Do not submit passwords, identity documents, financial details, medical records, private keys, or other sensitive information to an AI conversation.

Local knowledge-base mode does not require a remote AI request.

## Third-Party Services

The website contains links to third-party websites, AI services, tools, media, and assets. Those services have their own terms and privacy policies. Visiting them is outside the control of this repository.

## Data Sale

This project does not sell personal information.

## Security

Report suspected data exposure or privacy issues using [SECURITY.md](./SECURITY.md).
